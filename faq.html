Ajuda para usar as ferramentas da Artiva.

Esta área foi criada para ajudar quem não tem costume com tecnologia, medidas, arquivos de corte ou termos de posicionamento. A ideia é explicar de forma simples, como em uma conversa de ateliê.

Primeiros passos
Preciso entender de design para usar a Artiva?

Não. A proposta da Artiva é justamente guiar o processo. Você informa os dados principais, ajusta o que precisar e exporta o arquivo para produção.

O que eu preciso para usar o Gerador de Apliques?

Você precisa de uma arte base em PNG, JPG ou WEBP. O ideal é usar uma imagem com boa qualidade e, se possível, fundo transparente.

Por que os campos Nome e Idade começam vazios?

Para evitar que dados de exemplo saiam por engano na produção. Mesmo vazios, a prévia mostra “Nome” e “Idade” como guia visual.

Posso usar a ferramenta pelo celular?

A interface foi pensada para funcionar em telas menores, mas a produção de arquivos e ajustes finos costuma ser mais confortável no computador.

Medidas e posicionamento
O que significa X e Y?

X é a posição na horizontal, da esquerda para a direita. Y é a posição na vertical, de cima para baixo. Quando você ajusta “Nome Y”, por exemplo, está dizendo se o nome vai ficar mais para cima ou mais para baixo no aplique.

O que é margem de corte?

É uma folga ao redor da arte para o corte não ficar grudado demais no desenho. Uma margem pequena deixa o corte mais próximo; uma margem maior deixa mais respiro.

O que é espaço entre peças?

É a distância entre um aplique e outro na folha. Esse espaço ajuda na hora de cortar e evita que as peças fiquem muito coladas.

O que são colunas e linhas?

Colunas são quantas peças aparecem lado a lado. Linhas são quantas fileiras aparecem de cima para baixo. Por exemplo, 4 colunas e 4 linhas formam 16 peças na folha.

O que é A4?

A4 é o tamanho de folha mais comum para impressão caseira e de gráfica rápida. A ferramenta monta a prévia nesse formato para facilitar a produção.

Arquivos e exportação
Qual a diferença entre PNG e SVG?

PNG é uma imagem para prévia, divulgação ou impressão. SVG é um arquivo vetorial usado para corte, especialmente quando você precisa de contorno em máquinas ou softwares compatíveis.

Quando devo usar PNG prévia?

Use PNG para conferir visualmente a folha, mostrar para cliente, salvar uma imagem ou testar a arte antes da impressão.

Quando devo usar SVG corte?

Use SVG quando precisar do contorno de corte. Ele é útil para preparar o arquivo em fluxos de produção que aceitam vetor.

O que é página impressão?

É uma visualização já preparada para imprimir a folha A4. Ela ajuda a abrir a prévia em tamanho correto para produção.

Dúvidas de produção
A arte não apareceu. O que fazer?

Confira se o arquivo foi carregado corretamente e se está em PNG, JPG ou WEBP. Se a imagem for muito pesada, tente exportar uma versão menor e carregar novamente.

O texto ficou fora do lugar. Como ajusto?

Use os campos de posição, principalmente “Nome Y” e “Idade Y”. Aumentar o número desce o texto; diminuir o número sobe o texto.

O corte ficou muito perto da arte. O que mudo?

Aumente a margem de corte. Isso cria mais espaço ao redor do desenho no arquivo de contorno.

A grade ficou maior que a folha. O que significa?

Significa que o tamanho das peças, o espaço entre elas ou a quantidade de linhas e colunas não cabe na área segura da A4. Reduza o tamanho, diminua o espaço ou use menos peças.

O que são mockups?

Mockups são imagens de apresentação que mostram como a arte ficaria aplicada em um produto, como tubete, chaveiro, adesivo, ecobag ou placa MDF.
